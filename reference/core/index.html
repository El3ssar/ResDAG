    Core¶

    Model adds named inputs/outputs, fitted scaling and fit/forecast operations around a functional graph. Start with the common model guide. ESNModel remains the underlying symbolic graph with lower-level training and state interfaces. For timestamped runs, see TSDynamics trajectories. Several ports use named trajectories; per-port unit conversions use custom preprocessing.

    Use Feedback(output="prediction", input="state", delay=1) to declare a named recurrent connection. Prediction leads and feedback delays have separate meanings; see feedback and clocks.

    forward_stateless returns predictions and a ReservoirStates mapping without changing stored recurrent state. Reuse the returned mapping for differentiable chunks. Raw graph as_module() returns a ReservoirModelModule that shares the complete graph and its parameters; ReservoirFeatureExtractor selects reservoir features instead. These adapters serve different pipeline needs.

    Standard inherited PyTorch operations, including parameters, state_dict, load_state_dict, train, eval and to, remain available. Their inherited reference entries and checkpoint protocol hooks are omitted here.

    Core Model¶

    This module provides the main model class and input helpers for building ESN architectures using the pytorch_symbolic library.

    CLASS DESCRIPTION
    Model

    Named functional graph with training-only scaling and a PyTorch lifecycle.
    ESNModel

    Extended SymbolicModel with ESN-specific methods for forecasting and reservoir state management.
    ReservoirFeatureExtractor

    nn.Sequential-friendly adapter that packages reservoir layers as a drop-in feature extractor for ordinary torch.nn pipelines.
    Input

    Alias for pytorch_symbolic.Input for defining model inputs.
    FUNCTION DESCRIPTION
    reservoir_input

    Convenience constructor for a per-feature symbolic input tensor with a placeholder time dimension. Preferred over hand-crafting ps.Input((T, F)) since the time dimension is purely a tracing hint inside reservoir models.

    Examples:

    Building a simple ESN:

    >>> from resdag.core import ESNModel, reservoir_input
>>> from resdag.layers import ESNLayer
>>> from resdag.layers.readouts import CGReadoutLayer
>>>
>>> inp = reservoir_input(3)             # equivalent to ps.Input((1, 3))
>>> reservoir = ESNLayer(200, feedback_size=3)(inp)
>>> readout = CGReadoutLayer(200, 3)(reservoir)
>>> model = ESNModel(inp, readout)

    Multi-input model:

    >>> feedback = reservoir_input(3)
>>> driver = reservoir_input(5)
>>> reservoir = ESNLayer(200, feedback_size=3, input_size=5)(feedback, driver)
>>> readout = CGReadoutLayer(200, 3)(reservoir)
>>> model = ESNModel([feedback, driver], readout)
    See Also

    resdag.models : Premade ESN architectures. resdag.training.ESNTrainer : Trainer for fitting readouts.

    Bases: Module

    Wrap a named functional DAG in a common training/prediction workflow.

    Supply inputs={name: symbolic_input} and outputs={name: symbolic_output}, or graph=existing_model with optional ordered input_names and output_names. The graph is registered once as graph; it remains available for raw, already-normalized tensor execution. Existing symbolic, parallel local-state and coupled ensemble backends are supported. Parallel ports describe the full field; coupled members share one aggregate output. Coupled fitting trains member readouts only. A custom feed-forward aggregator is supplied/configured by the user and can be optimized separately with ordinary PyTorch. Reservoirs hidden inside an aggregator require ordinary stateful forward rather than explicit-state execution or forecasting.

    fit(series) learns future prediction for one input/output of equal width. fit(inputs, targets={output_name: tensor}) instead fits explicit, time-aligned targets; all streams include the same washout prefix. Declared intermediate heads may feed later reservoirs; readout_targets supervises internal fitted heads without adding them to public outputs.

    forward accepts floating Torch tensors, preserves 2-D/3-D layout and gradients, applies fitted scaling and returns original units. Calls carry recurrent state by default; call reset_state between unrelated sequences. One head returns a Tensor; several return a named dictionary.

    Preprocessing is "standard" by default, any existing normalization method, or "off"/None. Statistics use training inputs/targets after washout only. Implicit targets share their input's statistics. Feedback automatically converts each output back to original units before applying its destination input's scaling.

    prediction_lead declares the physical target distance for each head: input at step t predicts target at t + lead. The default is one; a mapping overrides named heads. feedback supplies explicit Feedback connections with independent graph-step delays. Without connections, the first output automatically feeds the first input after its prediction lead. An empty sequence leaves all inputs externally driven.

    state_dict includes scaling, ordered port metadata and the observed tail; reconstruct the same DAG before loading. tune compares candidates and installs a refitted winner; its report exposes the Optuna study. Complete save("run.pt") and rd.load preserve the complete model; diagram suffixes export its declared structure without running it.

    With the optional dynamics extra, bare or named TSDynamics trajectories use one shared observed clock. Explicit targets are aligned to each head's physical prediction lead. Forecasts return one trajectory or a named dictionary, with target component names and shared future times. return_type="tensor" keeps predictions on the model device. Ordinary forward always uses Torch tensors. Uneven timestamps are automatically interpolated with resample_method (linear, PCHIP or cubic); resample_dt controls the physical step.

    self,
    *,
    inputs: Mapping[str, SymbolicData] | None = None,
    outputs: Mapping[str, SymbolicData] | None = None,
    graph: nn.Module | None = None,
    input_names: Sequence[str] | None = None,
    output_names: Sequence[str] | None = None,
    washout: int = 100,
    preprocessing: Preprocessing = "standard",
    input_transforms: Mapping[str, nn.Module] | None = None,
    output_transforms: Mapping[str, nn.Module] | None = None,
    prediction_lead: int | Mapping[str, int] = 1,
    feedback: Sequence[Feedback] | None = None,
    resample_dt: float | None = None,
    resample_method: Literal["linear", "pchip", "cubic"] = "linear",
) -> None:
    super().__init__()
    self.washout = _washout(washout)
    self.resample_dt, self.resample_method = validate_resampling_options(
        resample_dt, resample_method
    )
    self._trajectory_context: dict[str, Any] | None = None
    object.__setattr__(self, "_trajectory_system", None)
    if preprocessing not in (
        None,
        "off",
        "minmax",
        "standard",
        "noncentered",
        "meanpreserving",
    ):
        raise ValueError("preprocessing must be a known normalization method, 'off', or None")
    self._preprocessing = None if preprocessing in (None, "off") else preprocessing
    if graph is not None:
        if inputs is not None or outputs is not None:
            raise ValueError("Supply graph= or named symbolic inputs/outputs, not both")
        backend = workflow_backend(graph)
        interface = backend.describe(graph)
        in_names = (
            input_names
            if input_names is not None
            else tuple(
                "input" if len(interface.input_widths) == 1 else f"input_{i}"
                for i in range(len(interface.input_widths))
            )
        )
        out_names = (
            output_names
            if output_names is not None
            else tuple(
                "output" if len(interface.output_widths) == 1 else f"output_{i}"
                for i in range(len(interface.output_widths))
            )
        )
    else:
        if input_names is not None or output_names is not None:
            raise ValueError("input_names/output_names belong to the graph= constructor")
        if (
            not isinstance(inputs, Mapping)
            or not inputs
            or not isinstance(outputs, Mapping)
            or not outputs
        ):
            raise ValueError("Provide non-empty named symbolic inputs and outputs, or graph=")
        if not all(
            isinstance(node, SymbolicData) for node in (*inputs.values(), *outputs.values())
        ):
            raise TypeError("inputs and outputs must map names to symbolic graph nodes")
        in_names, out_names = tuple(inputs), tuple(outputs)
        _port_names(in_names, len(inputs), "inputs")
        _port_names(out_names, len(outputs), "outputs")
        graph = ESNModel(tuple(inputs.values()), tuple(outputs.values()))
        backend = workflow_backend(graph)
        interface = backend.describe(graph)
    self.input_names = _port_names(in_names, len(interface.input_widths), "input_names")
    self.output_names = _port_names(out_names, len(interface.output_widths), "output_names")
    self.graph = graph
    self._backend = backend
    self._backend_interface_schema = interface.schema
    self._backend_schema = backend.checkpoint_schema(graph, interface)
    self._backend_references = interface.references
    self._input_widths = interface.input_widths
    self._output_widths = interface.output_widths
    self._prediction_leads = prediction_leads(prediction_lead, self.output_names)
    self._feedback = feedback_specs(feedback)
    self._feedback_plan(validate_widths=self._feedback is not None)
    method = cast(NormMethod, self._preprocessing or "standard")
    overrides = []
    for mapping, names in (
        (input_transforms, self.input_names),
        (output_transforms, self.output_names),
    ):
        if mapping is not None and (
            not isinstance(mapping, Mapping) or set(mapping) - set(names)
        ):
            raise ValueError(
                f"Transform override keys must be declared port names: {list(names)}"
            )
        overrides.append(dict(mapping or {}))
    self._custom_inputs = tuple(name in overrides[0] for name in self.input_names)
    self._custom_outputs = tuple(name in overrides[1] for name in self.output_names)
    originals = tuple(module for mapping in overrides for module in mapping.values())
    if any(not isinstance(module, nn.Module) for module in originals):
        raise TypeError("Transform overrides must be torch.nn.Module instances")
    validate_transform_ownership(graph, originals)
    for mapping, names, widths in (
        (overrides[0], self.input_names, self._input_widths),
        (overrides[1], self.output_names, self._output_widths),
    ):
        for name, width in zip(names, widths):
            if name in mapping:
                validate_custom_transform(mapping[name], width)
    self.input_scalers = nn.ModuleList(
        overrides[0].get(name, FittedNormalization(method)) for name in self.input_names
    )
    self.output_scalers = nn.ModuleList(
        overrides[1].get(name, FittedNormalization(method)) for name in self.output_names
    )
    reference = module_reference(graph)
    if reference is not None:
        self.input_scalers.to(device=reference.device, dtype=reference.dtype)
        self.output_scalers.to(device=reference.device, dtype=reference.dtype)
    self._transform_schema = self._custom_transform_schema()
    for group, masks, widths in (
        ("input", self._custom_inputs, self._input_widths),
        ("output", self._custom_outputs, self._output_widths),
    ):
        for index, (custom, width) in enumerate(zip(masks, widths)):
            if custom:
                with torch.inference_mode(False):
                    sample = (
                        torch.zeros(1, 3, width)
                        if reference is None
                        else reference.new_zeros(1, 3, width)
                    )
                self.register_buffer(f"_{group}_transform_sample_{index}", sample)
    for index, width in enumerate(self._input_widths):
        empty = torch.empty(0, width) if reference is None else reference.new_empty(0, width)
        self.register_buffer(f"_history_{index}", empty)
    self.register_buffer(
        "_fitted", torch.tensor(False, device=None if reference is None else reference.device)
    )
    self._fitted_flag = False
    self.register_load_state_dict_post_hook(self._synchronize_loaded_buffers)

    def forward_stateless(
    self,
    inputs: Streams,
    *,
    states: Mapping[str, torch.Tensor] | None = None,
    compile: bool = False,
) -> tuple[WorkflowOutput, ReservoirStates]:
    """Predict original units with caller-managed recurrent states and gradients."""
    self._require_scaling()
    self._backend.validate_stateless(self.graph)
    from resdag.core._hooks import call_with_states, has_execution_hooks, state_paths

    if has_execution_hooks(self):
        return cast(
            tuple[WorkflowOutput, ReservoirStates],
            call_with_states(
                self, (inputs,), states, state_paths(self, "graph."), compile=compile
            ),
        )
    values, was_2d = self._streams(inputs, self.input_names, self._input_widths, "inputs")
    output, final = recurrent_graph(self.graph).forward_stateless(
        *self._scaled_inputs(values), states=states, compile=compile
    )
    return self._outputs(output, was_2d), final

    def fit(
    self,
    training: Streams | Trajectory | Mapping[str, Trajectory],
    targets: Streams | Trajectory | Mapping[str, Trajectory] | None = None,
    *,
    readout_targets: Mapping[str, torch.Tensor] | None = None,
) -> Model:
    """Fit public and internal heads transactionally and retain the original observed tail.

    Implicit supervision pairs input `t` with observation
    `t + prediction_lead` and retains the complete observed tail.
    Explicit targets are already caller-aligned to input indices; declared
    leads describe their physical timestamps without shifting those arrays.
    Successful fitting resets streaming state. Failed fitting leaves the
    existing graph, fitted preprocessing and cached history unchanged.
    Bare or named TSDynamics trajectories share one physical input grid.
    Explicit trajectory targets are sampled at origin + prediction_lead*dt;
    tensors remain caller-aligned. Regression uses jointly supported origins
    after absolute washout. Target source observations after the common input
    endpoint are held out before interpolation. The cached tail includes the
    final observed inputs, even after the last supervised origin. Tensor
    refitting clears trajectory defaults on success.

    `readout_targets={"stage1": tensor}` supervises internal readouts
    without exposing them as outputs. Keys use the readout's `name` or
    graph path; coupled members use `models.<index>.<name>`. Tensors share
    the complete input time axis, including washout, and express the desired
    internal output units without automatic output scaling. For trajectory
    inputs, align these tensors to the prepared shared input grid.
    """
    self._validate_ports()
    implicit = targets is None
    if is_trajectory(training) or has_trajectory_port(training):
        prepared = prepare_trajectory_ports(
            training,
            input_names=self.input_names,
            input_widths=self._input_widths,
            output_names=self.output_names,
            output_widths=self._output_widths,
            prediction_leads=self._prediction_leads,
            targets=targets,
            dt=self.resample_dt,
            method=self.resample_method,
        )
        reference = module_reference(self.graph)
        dtype = None if reference is None else reference.dtype
        device = None if reference is None else reference.device
        inputs = {
            name: torch.tensor(data, dtype=dtype, device=device)
            for name, data in zip(self.input_names, prepared.inputs)
        }
        labels = {
            name: torch.tensor(data, dtype=dtype, device=device)
            for name, data in zip(self.output_names, prepared.targets)
        }
        return self._fit_prepared(
            inputs,
            labels,
            supervised_start=prepared.supervised_start,
            supervised_stop=prepared.supervised_stop,
            implicit=implicit,
            trajectory_context=prepared.context,
            trajectory_system=prepared.output_systems,
            readout_targets=readout_targets,
        )
    if is_trajectory(targets) or has_trajectory_port(targets):
        raise TypeError(
            "Trajectory targets require clocked Trajectory training inputs; "
            "Tensor targets remain caller-aligned"
        )
    values, was_2d = self._streams(
        cast(Streams, training), self.input_names, self._input_widths, "training", finite=True
    )
    stop = values[0].shape[1]
    if implicit:
        if (
            len(values) != 1
            or len(self.output_names) != 1
            or self._input_widths != self._output_widths
        ):
            raise ValueError(
                "Implicit fitting requires one input/output of equal width; "
                "provide explicit named targets for custom graphs"
            )
        lead = self._prediction_leads[0]
        stop -= lead
        labels = {
            self.output_names[0]: (
                values[0][:, lead:].squeeze(0) if was_2d else values[0][:, lead:]
            )
        }
    else:
        target_values, targets_2d = self._streams(
            cast(Streams, targets),
            self.output_names,
            self._output_widths,
            "targets",
            finite=True,
        )
        if targets_2d != was_2d or any(
            value.shape[:2] != values[0].shape[:2] for value in target_values
        ):
            raise ValueError("Explicit targets must share training batch/time axes and layout")
        labels = {
            name: value.squeeze(0) if was_2d else value
            for name, value in zip(self.output_names, target_values)
        }
    return self._fit_prepared(
        cast(Streams, training),
        labels,
        supervised_start=0,
        supervised_stop=stop,
        implicit=implicit,
        readout_targets=readout_targets,
    )

    def forecast(
    self,
    history: Streams | Trajectory | Mapping[str, Trajectory] | None = None,
    *,
    horizon: int,
    future_inputs: Streams | Trajectory | Mapping[str, Trajectory] | None = None,
    return_warmup: bool = False,
    compile: bool = False,
    execution: Literal["fast", "history"] = "fast",
    return_type: Literal["auto", "tensor", "trajectory"] = "auto",
) -> WorkflowOutput | Trajectory | dict[str, Trajectory]:
    """Return named heads aligned to the immediate unseen physical sample.

    `future_inputs` names every input without a feedback connection.
    Drivers start immediately after history and require
    `max(0, horizon - min(prediction_leads))` samples. With the default
    next-step head this is `horizon - 1`. History must contain at least
    the largest prediction lead and feedback delay. Warmup predictions
    already provide the first unseen samples; they are never skipped.
    `return_warmup` prepends predictions on the shared physical timeline
    starting at history index `max(prediction_leads)`.

    Every call rebuilds pending feedback from history and temporarily
    disables training noise. `execution='fast'` requires pointwise graph
    modules or explicit reservoir adapters. `'history'` replays the full
    growing input prefix for pure causal sequence modules, at higher cost.
    Custom modules may declare `supports_framewise=True` when appropriate.
    Compiled forecasting is currently available for symbolic graphs only;
    parallel and coupled backends require `compile=False`.

    `return_type="auto"` returns a TSDynamics trajectory after trajectory
    fitting or with trajectory history; otherwise it returns tensors.
    `"tensor"` avoids conversion to NumPy/CPU. A selected trajectory result
    needs timestamped history or the cached training context; a new tensor
    history has no absolute clock. Trajectory history is resampled to the
    fitted physical step and must retain fitted component names/order.
    """
    self._require_scaling()
    if return_type not in ("auto", "tensor", "trajectory"):
        raise ValueError("return_type must be 'auto', 'tensor', or 'trajectory'")
    horizon = positive_step_count(horizon, "horizon")
    self._backend.validate_forecast(self.graph, compile=compile)
    validate_forecast_execution(self.graph, execution, compile=compile)
    from resdag.core._hooks import (
        eager_with_hooks,
        forecast_owner,
        has_execution_hooks,
        original_outputs,
    )

    owner = forecast_owner(self)
    hooked = has_execution_hooks(owner)
    if hooked:
        eager_with_hooks(compile)
        compile = False
    plan = self._feedback_plan()
    if any(not layer.is_fitted for _, layer in self._backend.fitted_readouts(self.graph)):
        raise RuntimeError(
            "Forecast requires fitted terminal readouts; call fit(training) first"
        )
    context = self._trajectory_context
    system = self._trajectory_system
    cached_history = history is None
    clocked_history = is_trajectory(history) or has_trajectory_port(history)
    if clocked_history:
        prepared = prepare_trajectory_port_history(
            history,
            input_names=self.input_names,
            input_widths=self._input_widths,
            output_names=self.output_names,
            output_widths=self._output_widths,
            context=context,
            dt=self.resample_dt,
            method=self.resample_method,
            output_systems=system,
        )
        context, system = prepared.context, prepared.output_systems
        reference = module_reference(self.graph)
        history = {
            name: torch.tensor(
                data,
                dtype=None if reference is None else reference.dtype,
                device=None if reference is None else reference.device,
            )
            for name, data in zip(self.input_names, prepared.inputs)
        }
    trajectory_output = return_type == "trajectory" or (
        return_type == "auto" and context is not None
    )
    if trajectory_output:
        if context is None or (not cached_history and not clocked_history):
            raise ValueError(
                "Trajectory output needs timestamped trajectory history or cached "
                "trajectory fitting history; pass a Trajectory or return_type='tensor'"
            )
        if set(context["outputs"]) != set(self.output_names):
            raise ValueError(
                "Trajectory output needs per-head target component metadata; "
                "fit Trajectory targets or choose return_type='tensor'"
            )
        trajectory_type()  # Optional dependency must fail before graph hooks execute.
    if history is None:
        if not self.is_fitted:
            raise RuntimeError("No cached history; provide history or call fit(training) first")
        history = {
            name: getattr(self, f"_history_{index}")
            for index, name in enumerate(self.input_names)
        }
    values, was_2d = self._streams(
        cast(Streams, history), self.input_names, self._input_widths, "history", finite=True
    )
    if values[0].shape[1] < plan.required_history:
        raise ValueError(
            f"history needs at least {plan.required_history} samples to seed all "
            "prediction leads and feedback delays"
        )
    driver_names = tuple(self.input_names[index] for index in plan.driver_indices)
    driver_widths = tuple(self._input_widths[index] for index in plan.driver_indices)
    steps = plan.future_steps(horizon)
    drivers: tuple[torch.Tensor, ...]
    if not driver_names:
        if future_inputs is not None:
            raise ValueError("This graph has no future driver inputs")
        drivers = ()
    elif future_inputs is None:
        if steps:
            raise ValueError(f"future_inputs requires driver keys {list(driver_names)}")
        drivers = tuple(values[index][:, :0] for index in plan.driver_indices)
    else:
        if is_trajectory(future_inputs) or has_trajectory_port(future_inputs):
            if context is None or (not cached_history and not clocked_history):
                raise ValueError(
                    "Trajectory drivers require timestamped or cached trajectory history; "
                    "new Tensor history has no absolute clock"
                )
            arrays = prepare_trajectory_port_drivers(
                future_inputs,
                input_names=driver_names,
                input_widths=driver_widths,
                last_time=context["clock"]["last_time"],
                dt=context["clock"]["dt"],
                steps=steps,
                method=self.resample_method,
                input_records=context["inputs"],
            )
            future_inputs = {
                name: torch.tensor(data, device=values[0].device, dtype=values[0].dtype)
                for name, data in zip(driver_names, arrays)
            }
        drivers, _ = self._streams(
            cast(Streams, future_inputs),
            driver_names,
            driver_widths,
            "future_inputs",
            finite=True,
            allow_empty=True,
        )
        if drivers[0].shape[0] != values[0].shape[0] or drivers[0].shape[1] < steps:
            raise ValueError(
                f"future_inputs must match the history batch and contain at least {steps} samples"
            )
    times = None
    if trajectory_output:
        assert context is not None
        times = trajectory_port_forecast_times(
            context,
            horizon,
            history_length=values[0].shape[1],
            warmup_lead=max(plan.leads),
            return_warmup=return_warmup,
        )
    default_route = (
        len(plan.routes) == 1
        and plan.routes[0] == FeedbackRoute(0, 0, 1)
        and all(lead == 1 for lead in plan.leads)
    )
    final_states = None
    output: ModelOutput
    with evaluating(owner):
        if not hooked and drivers and drivers[0].shape[1]:
            drivers = tuple(
                (
                    apply_transform(self.input_scalers[index], value)
                    if self._transform_active(output=False, index=index)
                    else value
                )
                for index, value in zip(plan.driver_indices, drivers)
            )
        if hooked:
            executor = ForecastSequenceExecutor(
                self.graph, execution, workflow=self, owner=owner
            )
            output, final_states = feedback_rollout(
                executor,
                values,
                drivers,
                plan,
                lambda route, value: value,
                horizon=horizon,
                return_warmup=return_warmup,
            )
        elif execution == "fast" and default_route and self._feedback_scaling_matches():
            output = self._backend.forecast(
                self.graph,
                self._scaled_inputs(values),
                drivers or None,
                horizon=horizon,
                return_warmup=return_warmup,
                compile=compile,
            )
        else:
            executor = ForecastSequenceExecutor(self.graph, execution, compile=compile)

            def bridge(route: FeedbackRoute, value: torch.Tensor) -> torch.Tensor:
                if self._transform_active(output=True, index=route.output_index):
                    value = apply_transform(
                        self.output_scalers[route.output_index], value, inverse=True
                    )
                if self._transform_active(output=False, index=route.input_index):
                    value = apply_transform(self.input_scalers[route.input_index], value)
                return value

            output, final_states = feedback_rollout(
                executor,
                self._scaled_inputs(values),
                drivers,
                plan,
                bridge,
                horizon=horizon,
                return_warmup=return_warmup,
            )
        result = (
            original_outputs(cast(tuple[torch.Tensor, ...], output), self.output_names, was_2d)
            if hooked
            else self._outputs(output, was_2d)
        )
    if not trajectory_output:
        if final_states is not None:
            self._commit_forecast_states(final_states)
        return result
    assert context is not None and times is not None
    # NumPy has no bfloat16 dtype. Conversion is confined to this explicit
    # CPU result boundary; tensor forecasts retain their device and dtype.
    result_values = (
        {self.output_names[0]: result} if isinstance(result, torch.Tensor) else result
    )
    result_arrays = {}
    for name, value in result_values.items():
        numpy_dtype = torch.float32 if value.dtype == torch.bfloat16 else value.dtype

        name for name, module in self.named_modules() if isinstance(module, BaseReservoirLayer)

    Notes
    -----
    Returned predictions have not yet been consumed as inputs. After a
    forecast, the stored state has consumed the history and all predictions
    except the final one. To continue without replaying history, pass empty
    warmup streams, `initial_feedback=prediction[:, -1:]` and `reset=False`
    (plus the corresponding future drivers).

    Hook-free autoregressive steps use a cached flat execution plan. When
    PyTorch execution hooks are registered, native module calls preserve
    their behavior during warmup and generated steps. Hooks added or removed
    after an earlier forecast take effect automatically. Registered hooks
    select eager compatible execution when `compile=True` is requested.
    Custom non-reservoir operations must declare `supports_framewise=True`.
    Whole-sequence custom operations can use the common `Model` wrapper's
    `forecast(execution="history")` instead.

    Examples
    --------
    >>> predictions = model.forecast(observed, horizon=100)
    >>> # predictions[:, 0] estimates the sample immediately after observed.
    """
    validate_fast_plan(self._get_execution_plan())
    warmup_inputs, drivers, horizon, boundary = prepare_forecast_inputs(
        warmup_inputs,
        forecast_inputs,
        num_inputs=len(self.inputs),
        horizon=horizon,
        initial_feedback=initial_feedback,
        alignment=alignment,
    )
    if compile and not no_grad:
        raise ValueError(
            "forecast(compile=True) is incompatible with no_grad=False: the "
            "reduce-overhead/cudagraph step path does not support autograd. "
            "Use no_grad=False with compile=False for a differentiable rollout."
        )

    output_shape = self.output_shape
    multi_output = isinstance(output_shape, tuple) and isinstance(output_shape[0], torch.Size)
    feedback_dim = warmup_inputs[0].shape[-1]
    feedback_output_dim = output_shape[0][-1] if multi_output else output_shape[-1]
    if feedback_output_dim != feedback_dim:
        raise ValueError(
            "forecast(): feedback dimension mismatch. "
            f"Feedback input has {feedback_dim} features but the model output "
            f"used as feedback has {feedback_output_dim} features. "
            "For autoregressive forecasting the first output must match the feedback input dimension."
        )

    warmup_outputs = self.warmup(
        *warmup_inputs, return_outputs=True, reset=reset, no_grad=no_grad
    )
    assert warmup_outputs is not None
    outputs = warmup_outputs if isinstance(warmup_outputs, tuple) else (warmup_outputs,)
    assert all(isinstance(out, torch.Tensor) for out in outputs)
    with _grad_context(no_grad):
        seed = initial_feedback if initial_feedback is not None else outputs[0][:, -1:, :]
        steps = horizon - int(boundary)
        if steps:
            flat = self._get_flat_step()
            states: list[torch.Tensor] = []
            for reservoir in flat.reservoir_layers:
                if reservoir.state is None:
                    reservoir._maybe_init_state(
                        warmup_inputs[0].shape[0], seed.device, seed.dtype
                    )
                assert reservoir.state is not None
                states.append(reservoir.state)
            forecast_buffers, states = rollout(
                flat,
                seed,
                drivers,
                states,
                steps,
                [out.shape[-1] for out in outputs],
                no_grad=no_grad,
                compile=compile,
                output_templates=outputs,
            )
            for reservoir, state in zip(flat.reservoir_layers, states):
                if reservoir.detach_state_between_calls and state.grad_fn is not None:
                    reservoir.state = state.detach().clone()
                else:
                    reservoir.state = state.clone()
        else:
            forecast_buffers = [out[:, :0, :] for out in outputs]

        predictions = []
        for warm, generated in zip(outputs, forecast_buffers):
            if boundary:
                generated = torch.cat((warm[:, -1:, :], generated), dim=1)
            if return_warmup:
                prefix = warm[:, :-1, :] if boundary else warm
                generated = torch.cat((prefix, generated), dim=1)
            predictions.append(generated)
        return tuple(predictions) if multi_output else predictions[0]

    *driver_series: torch.Tensor,

    """
    Gap-filling reconstruction by alternating re-sync and free-running.

    Reconstruct a long trajectory that is only *observed* in periodic
    windows: the reservoir is repeatedly re-synchronized on a short window
    of real data (teacher forcing) and then left to forecast autonomously
    across the unobserved gap.  Because the Echo State Property gives the
    reservoir fading memory, every teacher-forced window pulls its state
    back onto the true trajectory, no matter how far the previous free run
    had drifted — so per-window error does not compound across windows
    (accuracy *within* a gap still depends on keeping `predict_len` short
    relative to the system's predictability horizon).

    The reservoir state is carried across the whole pass (it is reset only
    once, at the start, and only when `reset=True`).  Each cycle is one
    `forecast` call: its warmup phase is the re-sync window and its
    autoregressive phase is the gap.

    Timeline (`W = warmup_len`, `F = teacher_len`, `P = predict_len`):

    ```text
    [== warmup W ==][~~ gap P ~~][= teacher F =][~~ gap P ~~][= F =]...
      observed         filled       observed       filled      obs
    (teacher-forced)  (forecast)  (teacher-forced) (forecast)
    ```

    Observed segments are copied verbatim from `series`; gap segments are
    replaced by the model's autonomous forecast.  Any trailing steps that
    cannot host a full re-sync window plus at least one forecast step are
    left as observed.

    Parameters
    ----------
    series : torch.Tensor
        Ground-truth feedback series of shape `(batch, T, feedback_dim)`.
        It is both the source of every teacher-forced window and the value
        returned on observed segments.
    *driver_series : torch.Tensor
        Exogenous driver series, one per driver input of the model, each of
        shape `(batch, T, driver_dim)` spanning the full timeline.  Omit
        for feedback-only models.  Unlike `forecast` (which takes
        *separate* warmup and `forecast_inputs` driver tuples), here each
        driver covers the whole `T`-step timeline and is sliced internally
        per cycle.
    predict_len : int, keyword-only
        Length `P` of each autonomous forecast window (the gap to fill).
        Must be `>= 1`.
    teacher_len : int, keyword-only
        Length `F` of each teacher-forced re-synchronization window.
        Must be `>= 1`.  Longer windows re-sync more reliably; shorter
        windows observe less of the signal.
    warmup_len : int, optional
        Length `W` of the initial teacher-forced window.  Defaults to
        `teacher_len`.
    reset : bool, default=True
        If True, reservoir states are reset before the first window.  Set
        False to continue from the current (already warmed) state.
    return_mask : bool, default=False
        If True, also return a 1-D boolean mask of length `T` that is
        True where the reconstruction is a real value and False where it is
        a model forecast (see Returns).
    no_grad : bool, default=True
        If True (default), every cycle runs under `torch.no_grad` —
        graph-free and identical to the historical `@torch.no_grad()`
        decorator.  Set `False` to make the gap-fill reconstruction
        **differentiable**: the value threaded into the reconstruction on
        every forecast segment carries an autograd graph, so a loss over the
        gaps (`reconstruction[:, ~mask]`) can be back-propagated through the
        BPTT unroll of each window into the trainable reservoir and readout
        parameters.  The flag is threaded into the per-cycle `forecast`
        calls; the same memory cost and
        `reservoir.detach_state_between_calls` caveats documented on
        `forecast` apply, multiplied across cycles (state is carried
        across windows, so detaching it severs gradients window-to-window).

    Returns
    -------
    reconstruction : torch.Tensor
        Reconstructed series of shape `(batch, T, feedback_dim)`: real
        values on observed segments, forecasts on the gaps.
    mask : torch.Tensor
        Only if `return_mask=True`.  Boolean tensor of shape `(T,)`,
        True where the step is a real value (a teacher-forced window, or the
        untouched trailing remainder copied verbatim from `series`) and
        False where it is a model forecast.

    Raises
    ------
    ValueError
        If `series` is not 3-D, if `predict_len`/`teacher_len`/
        `warmup_len` are not positive, if the number of `driver_series`
        does not match the model's drivers, if any driver does not span
        `T` steps, or if `series` is too short for even one cycle.

    Notes
    -----
    - The forecast steps to score are exactly `reconstruction[:, ~mask]`
      against `series[:, ~mask]` — the values the model had to infer
      without ever seeing them.
    - For multi-output models the first output is fed back (as in
      `forecast`) and only that channel is reconstructed.

    Examples
    --------
    Reconstruct a Lorenz trajectory observed 40 steps out of every 240,
    filling 200-step gaps:

    >>> recon, mask = model.windowed_forecast(

    ...     predict_len=200,

    >>> recon = model.windowed_forecast(

    ...     predict_len=100, teacher_len=50,
    ... )

    --------
    forecast : A single warmup + autoregressive forecast cycle.
    warmup : Teacher-forced state synchronization only.
    """
    if series.dim() != 3:
        raise ValueError(
            f"series must be 3-D (batch, T, feedback_dim); got shape {tuple(series.shape)}."
        )
    predict_len = positive_step_count(predict_len, "predict_len")
    teacher_len = positive_step_count(teacher_len, "teacher_len")
    if warmup_len is None:
        warmup_len = teacher_len
    warmup_len = positive_step_count(warmup_len, "warmup_len")

    num_drivers = len(driver_series)
    expected_drivers = len(self.inputs) - 1
    if num_drivers != expected_drivers:
        raise ValueError(
            f"model has {expected_drivers} driver input(s) but {num_drivers} "
            f"driver_series were given. Pass one full-timeline driver series per "
            f"driver input (the feedback is supplied by `series`)."
        )

    _, total_steps, _ = series.shape
    for i, driver in enumerate(driver_series):
        if driver.dim() != 3:
            raise ValueError(
                f"driver_series[{i}] must be 3-D (batch, T, driver_dim); "
                f"got shape {tuple(driver.shape)}."
            )
        if driver.shape[1] != total_steps:
            raise ValueError(
                f"driver_series[{i}] spans {driver.shape[1]} steps but series spans "
                f"{total_steps}; drivers must cover the full timeline."
            )

    # ``no_grad`` is also threaded into each per-cycle ``forecast`` below; the
    # context here additionally covers the in-place reconstruction writes so
    # that, when differentiable, the forecast segments graft their autograd
    # graph onto the (cloned) reconstruction via ``CopySlices``.
    reconstruction = series.clone()
    mask = torch.ones(total_steps, dtype=torch.bool, device=series.device)

    pos = 0
    window_len = warmup_len
    ran_a_cycle = False
    with _grad_context(no_grad):
        while True:
            teacher_end = pos + window_len
            # Stop once a full re-sync window leaves no room to forecast. The
            # guard guarantees ``teacher_end < total_steps`` below, so the gap
            # (clamped to whatever remains) is always at least one step.
            if teacher_end >= total_steps:
                break
            gap = min(predict_len, total_steps - teacher_end)

            teacher_window = series[:, pos:teacher_end, :]
            if num_drivers:
                warmup_inputs: tuple[torch.Tensor, ...] = (
                    teacher_window,
                    *(d[:, pos:teacher_end, :] for d in driver_series),
                )
                forecast_inputs: tuple[torch.Tensor, ...] | None = tuple(
                    d[:, teacher_end : teacher_end + gap, :] for d in driver_series
                )
            else:
                warmup_inputs = (teacher_window,)
                forecast_inputs = None

            # Generate one additional prediction so the final gap sample is
            # consumed too. Its value is discarded, but this advances state
            # through the entire gap before the next observed window.
            full = self.forecast(
                warmup_inputs,
                forecast_inputs=forecast_inputs,
                horizon=gap + 1,
                reset=reset and not ran_a_cycle,
                no_grad=no_grad,
            )
            feedback_full = full[0] if isinstance(full, tuple) else full
            gap_preds = feedback_full[:, :gap, :]
            reconstruction[:, teacher_end : teacher_end + gap, :] = gap_preds
            mask[teacher_end : teacher_end + gap] = False

            ran_a_cycle = True
            pos = teacher_end + gap
            window_len = teacher_len

    if not ran_a_cycle:
        raise ValueError(
            f"series length ({total_steps}) is too short for even one cycle: the "
            f"initial warmup window (warmup_len={warmup_len}) leaves no room to "
            f"forecast (need at least warmup_len + 1 = {warmup_len + 1} steps; the "
            f"final gap is clamped to whatever remains)."
        )

    if return_mask:
        return reconstruction, mask
    return reconstruction

    nn.Sequential-friendly reservoir feature extractor.

    Wraps one reservoir layer (or a stack of them) as a plain torch.nn.Module that maps a feedback sequence (batch, timesteps, feedback_size) (plus an optional driving input) to reservoir features (batch, timesteps, reservoir_size).     Stacking is supported: passing several feedback dimensions, or constructing the extractor from pre-built layers, chains the reservoirs so each consumes the previous reservoir's features as its feedback signal. A driving input, when supplied, is passed to the first reservoir only.

    TYPE: int or sequence of int DEFAULT: None

    feedback_size

    Dimension of the feedback signal entering the first reservoir. Required unless layers is given. For stacked reservoirs only the first layer's feedback size is taken from this argument; the feedback size of each subsequent layer is the previous layer's reservoir size.

    ValueError

    arbitrary parallel branches, intermediate transforms, or the trained
    readout. Embed the source model itself to preserve its full graph.

    >>> from resdag import ReservoirFeatureExtractor

    self,
    feedback: torch.Tensor,
    *driving_inputs: torch.Tensor,

    Map a feedback sequence to reservoir features.

    Parameters
    ----------
    feedback : torch.Tensor
        Feedback signal of shape `(batch, timesteps, feedback_size)`.
    *driving_inputs : torch.Tensor
        Optional driving input of shape `(batch, timesteps, input_size)`,
        passed to the **first** reservoir only.  At most one is supported.

    -------
    torch.Tensor

    ------
    ValueError

    `reset_state` is invoked. With `stateful=False`, every call
    starts from zeros. When the extractor sits inside a
    `torch.nn.Sequential` only `feedback` is passed, satisfying
    the single-positional-input contract.

    if len(driving_inputs) > 1:
        raise ValueError("Only one driving input tensor allowed")
    if not self.stateful:
        independent_features, _ = self.forward_stateless(feedback, *driving_inputs)
        return independent_features

    # The driving input enters the first reservoir; deeper reservoirs
    # consume the previous layer's features as their (sole) feedback.
    layers = self._layers
    features: torch.Tensor = layers[0](feedback, *driving_inputs)
    for reservoir in layers[1:]:
        features = reservoir(features)
    return features

    def forward_stateless(
    self,
    feedback: torch.Tensor,
    *driving_inputs: torch.Tensor,
    states: Iterable[torch.Tensor] | None = None,
    compile: bool = False,
) -> tuple[torch.Tensor, tuple[torch.Tensor, ...]]:
    """Extract features with explicit state, without changing stored states.

    `feedback` and the optional driver have shape `(batch, time, features)`. `states` contains one initial state per wrapped
    reservoir; omit it to start every reservoir from zeros. The result is
    `(features, final_states)`. Pass `final_states` into a later call
    to continue the same stream. States retain their autograd graphs;
    detach them explicitly to truncate gradients between chunks.

    `compile=True` opts into the layers' inference-only CUDA scan;
    differentiable inputs or states keep the eager path.
    """
    if feedback.dim() != 3:
        raise ValueError(f"Feedback must be 3D (B, T, F), got shape {feedback.shape}")
    if len(driving_inputs) > 1:
        raise ValueError("Only one driving input tensor allowed")
    for driver in driving_inputs:
        if driver.dim() != 3 or driver.shape[:2] != feedback.shape[:2]:
            raise ValueError(
                "Driving input must be 3D and match feedback batch/time dimensions"
            )

    layers = self._layers
    initial = tuple(states) if states is not None else None
    if initial is not None and len(initial) != len(layers):
        raise ValueError(f"Expected {len(layers)} reservoir states, got {len(initial)}")

    features = feedback
    final: list[torch.Tensor] = []
    for i, layer in enumerate(layers):
        state = (
            layer.cell.init_state(features.shape[0], features.device, features.dtype)
            if initial is None
            else initial[i]
        )
        layer.cell.validate_state(state)
        if state.shape[0] != features.shape[0]:
            raise ValueError("State batch size must match feedback batch size")
        inputs = [features, *driving_inputs] if i == 0 else [features]
        features, state = layer.forward_stateless(inputs, state, compile=compile)
        final.append(state)
    return features, tuple(final)
