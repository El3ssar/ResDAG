    Data and datasets¶

    resdag.data is the canonical home for time-series preparation, file I/O and windowed datasets. resdag.datasets contains benchmark generators. Existing imports through resdag.utils.data use the same functions.

    Tensor preparation¶

    prepare_esn_data accepts (batch, time, features) and returns warmup, train, target, forecast-warmup and validation tensors. Its default alignment="next" includes the final observed training target in forecast warmup, so forecasts align with the held-out validation tensor. Inspect the alignment option when working with older experiments.

    normalize_data fits statistics on exactly the tensor passed to it. To apply one transformation to later observations, retain those statistics and pass them back through stats=; denormalize_data restores the original units. Keep final test observations out of any statistics fitted for model selection.

    def prepare_esn_data(
    data: torch.Tensor,
    warmup_steps: int,
    train_steps: int,
    val_steps: int | None = None,
    discard_steps: int = 0,
    normalize: bool = False,
    norm_method: NormMethod = "minmax",
    return_stats: bool = False,
    alignment: ForecastAlignment = "next",
) -> ESNDataSplits | ESNDataSplitsWithStats:
    """Prepare time series data for ESN training and forecasting.

    Splits data into segments appropriate for ESN workflows:
    1. Warmup: Initial steps for reservoir state synchronization
    2. Train: Training input data
    3. Target: Training targets (train data shifted by 1 step)
    4. Forecast warmup: Last warmup_steps of all observed data, including the
       final training target, for forecast initialization
    5. Validation: Held-out data starting after that final training target.

    Data layout (`train_end = warmup_steps + train_steps`):

    ```text
    [discard][warmup][------- train -------][s][------ val ------]
    ```

    `s` is `data[train_end]`: the final training target, which is already
    observed during fitting. The forecast warmup includes it. Its readout
    predicts the first held-out value, `data[train_end + 1]`, so
    `forecast(forecast_warmup, horizon=val_steps)` lines up element-for-element
    with `val` (no manual shift).


    Parameters
    ----------
    data : torch.Tensor
        Input time series of shape (B, T, D).
    warmup_steps : int
        Number of steps for reservoir warmup/synchronization.
    train_steps : int
        Number of training steps (after warmup).
    val_steps : int, optional
        Number of validation steps. If None, uses all remaining data.
    discard_steps : int, default=0
        Number of initial steps to discard (e.g., initial transients).
    normalize : bool, default=False
        Whether to normalize data. If True, statistics are computed from
        training data and applied to all splits globally.
    norm_method : str, default="minmax"
        Normalization method if normalize=True.
    return_stats : bool, default=False
        If True, append the fitted normalization statistics as a 6th return
        element so the normalize -> forecast -> report loop can be closed via
        `denormalize_data`. The element is the `stats` dict when
        `normalize=True` and `None` when `normalize=False` (nothing was
        fitted). When False (the default), the legacy 5-tuple is returned
        unchanged.
    alignment : str, optional
        `"next"` includes the final training target in the forecast history.
        `"legacy"` ends that history one sample earlier; pair this with
        `model.forecast(..., alignment="legacy")` to reproduce old runs.
        Training and validation windows are identical in both modes.

    Returns
    -------
    warmup : torch.Tensor
        Warmup data, shape (B, warmup_steps, D).
    train : torch.Tensor
        Training input, shape (B, train_steps, D).
    target : torch.Tensor
        Training target (shifted by 1), shape (B, train_steps, D).
    forecast_warmup : torch.Tensor
        Last warmup_steps of the observed prefix for forecast init, shape
        (B, warmup_steps, D). Includes earlier warmup history if train_steps
        is shorter than warmup_steps.
    val : torch.Tensor
        Validation data, shape (B, val_steps, D). Starts at `data[train_end + 1]`
        so it aligns directly with an autoregressive `forecast` of the same
        horizon. The final training target belongs to the observed history.
    stats : dict or None
        Only returned when `return_stats=True`. The fitted normalization
        statistics (as returned by `normalize_data`) when `normalize=True`,
        otherwise `None`. Pass to `denormalize_data` to map forecasts
        back to the original scale.

    Raises
    ------
    ValueError
        If `warmup_steps` or `train_steps` is not strictly positive, if
        `discard_steps` is negative, if `val_steps` is negative, or if the
        data is too short for the requested splits.

    Warns
    -----
    UserWarning
        If the resulting validation window is empty (`val_steps=0` or the data
        is exhausted by warmup, training inputs, and their final target), so no held-out validation data
        remains.

    See Also
    --------
    denormalize_data : Inverts the normalization using the returned `stats`.

    Examples
    --------
    >>> data = torch.randn(1, 1000, 3)  # (batch=1, time=1000, features=3)
    >>> warmup, train, target, f_warmup, val = prepare_esn_data(
    ...     data, warmup_steps=100, train_steps=500, val_steps=200
    ... )
    >>> print(warmup.shape)   # (1, 100, 3)
    >>> print(train.shape)    # (1, 500, 3)
    >>> print(target.shape)   # (1, 500, 3)
    >>> print(f_warmup.shape) # (1, 100, 3)
    >>> print(val.shape)      # (1, 200, 3)

    Close the round-trip by keeping the fitted stats and inverting later:

    >>> warmup, train, target, f_warmup, val, stats = prepare_esn_data(
    ...     data, warmup_steps=100, train_steps=500, val_steps=200,
    ...     normalize=True, norm_method="minmax", return_stats=True,
    ... )
    >>> val_physical = denormalize_data(val, "minmax", stats)  # original units
    """
    _validate_series_shape(data)
    validate_alignment(alignment)
    _, timesteps, _ = data.shape
    warmup_steps = _validate_step_count("warmup_steps", warmup_steps)
    train_steps = _validate_step_count("train_steps", train_steps)
    discard_steps = _validate_step_count("discard_steps", discard_steps, allow_zero=True)
    if val_steps is not None:
        val_steps = _validate_step_count("val_steps", val_steps, allow_zero=True)

    # Validate discard_steps
    if discard_steps >= timesteps:
        raise ValueError(
            f"discard_steps ({discard_steps}) must be less than data length ({timesteps})"
        )

    # Trim initial steps
    data = data[:, discard_steps:, :]
    timesteps = data.shape[1]

    # Calculate required length
    train_end = warmup_steps + train_steps

    if train_end >= timesteps:
        raise ValueError(
            f"warmup_steps + train_steps ({train_end}) exceeds "
            f"available data length ({timesteps}) after discarding {discard_steps} steps"
        )

    # The final supervised target data[train_end] is already observed. Include
    # it in canonical forecast history, then hold out data[train_end + 1] onward.
    # Legacy preparation omits that observation from history and relies on the
    # old forecast's additional predicted-seed update to reach the same val index.
    val_start = train_end + 1
    if val_steps is None:
        val_steps = timesteps - val_start
        if val_steps == 0:
            warnings.warn(
                "Validation window is empty: warmup + training inputs + their final "
                f"target consume all {timesteps} available steps (after discarding "
                f"{discard_steps}), leaving no held-out data for val. Reduce "
                "warmup_steps/train_steps or supply more data if you need a val split.",
                UserWarning,
                stacklevel=2,
            )
    else:
        required = val_start + val_steps
        if required > timesteps:
            raise ValueError(
                f"Required data ({required} = warmup + train + 1 final target + val) "
                f"exceeds available length ({timesteps}). The +1 supplies the final "
                "supervised target data[train_end], which is already observed "
                "and must precede held-out validation."
            )
        if val_steps == 0:
            warnings.warn(
                "val_steps=0 produces an empty validation split. Pass a positive "
                "val_steps (or None to use all remaining data) if you need a val "
                "window.",
                UserWarning,
                stacklevel=2,
            )

    # Split data
    warmup = data[:, :warmup_steps, :]
    train = data[:, warmup_steps:train_end, :]
    target = data[:, warmup_steps + 1 : train_end + 1, :]
    # Include earlier observed history when train_steps < warmup_steps.
    forecast_end = train_end + (alignment == "next")
    forecast_warmup = data[:, forecast_end - warmup_steps : forecast_end, :]
    val = data[:, val_start : val_start + val_steps, :]

    # Optional normalization (compute stats from training data only)
    stats: dict[str, torch.Tensor] | None = None
    if normalize:
        stats = _compute_stats(train, norm_method)
        warmup = _apply_norm(warmup, norm_method, stats)
        train = _apply_norm(train, norm_method, stats)
        target = _apply_norm(target, norm_method, stats)
        forecast_warmup = _apply_norm(forecast_warmup, norm_method, stats)
        val = _apply_norm(val, norm_method, stats)

    if return_stats:
        return warmup, train, target, forecast_warmup, val, stats
    return warmup, train, target, forecast_warmup, val

    def normalize_data(
    data: torch.Tensor,
    method: NormMethod = "minmax",
    stats: dict[str, torch.Tensor] | None = None,
) -> tuple[torch.Tensor, dict[str, torch.Tensor]]:
    """Normalize time series data globally.

    Computes statistics across all batches and timesteps, applying the same
    normalization to the entire dataset. This is the correct approach when
    batches contain trajectories from the same dynamical system.

    Parameters
    ----------
    data : torch.Tensor
        Data tensor of shape (B, T, D).
    method : str
        Normalization method:
        - "minmax": Scale to [-1, 1] range
        - "standard": Zero mean, unit variance
        - "noncentered": Scale by max absolute value (preserves zero)
        - "meanpreserving": Scale deviations to [-1, 1], then restore mean
    stats : dict, optional
        Pre-computed statistics for normalization. If provided, these are used
        instead of computing from data. They are applied on the input device
        and dtype without modifying the supplied statistics.

    Returns
    -------
    normalized : torch.Tensor
        Normalized data with same shape as input.
    stats : dict
        Statistics used for normalization (for applying to other data).

    Examples
    --------
    >>> data = torch.randn(1, 100, 3)
    >>> normalized, stats = normalize_data(data, method="minmax")
    >>> # Apply same normalization to new data
    >>> new_normalized, _ = normalize_data(new_data, method="minmax", stats=stats)
    """
    _validate_series_shape(data)
    if stats is None:
        stats = _compute_stats(data, method)

    normalized = _apply_norm(data, method, stats)
    return normalized, stats

    denormalize_data ¶

    denormalize_data(data: Tensor, method: NormMethod, stats: dict[str, Tensor]) -> Tensor

    Invert normalize_data, mapping data back to its original scale.

    Applies the exact inverse of the transform that normalize_data (and prepare_esn_data(normalize=True, ...)) applied, using the fitted statistics. This closes the normalize -> forecast -> report loop: feed model predictions through denormalize_data to recover physical units, compute errors in the original scale, or plot against the raw series.

    PARAMETER DESCRIPTION
    data

    Normalized data of shape (B, T, D) to map back to the original scale.

    TYPE: Tensor

    method

    Normalization method that produced data. Must match the method used for the forward transform. The inverse of each method is:

    • "minmax": (data + 1) / 2 * range + min
    • "standard": data * std + mean
    • "noncentered": data * scale
    • "meanpreserving": (data - mean) * maxdev + mean

    TYPE: str

    stats

    Fitted statistics returned by normalize_data (or by prepare_esn_data with return_stats=True). The required keys depend on method: {"min", "range"} for "minmax", {"mean", "std"} for "standard", {"scale"} for "noncentered", and {"mean", "maxdev"} for "meanpreserving".

    TYPE: dict

    RETURNS DESCRIPTION
    Tensor

    Data restored to the original scale, with the same shape as data.
    RAISES DESCRIPTION
    ValueError

    If method is not a recognized normalization method.
    See Also

    normalize_data : The forward transform this function inverts. prepare_esn_data : Returns the fitted stats when return_stats=True.

    Examples:

    >>> data = torch.randn(1, 100, 3)
>>> normalized, stats = normalize_data(data, method="standard")
>>> restored = denormalize_data(normalized, method="standard", stats=stats)
>>> torch.allclose(restored, data, atol=1e-6)

    Applies the exact inverse of the transform that `normalize_data` (and
    `prepare_esn_data(normalize=True, ...)`) applied, using the fitted
    statistics. This closes the normalize -> forecast -> report loop: feed model
    predictions through `denormalize_data` to recover physical units, compute
    errors in the original scale, or plot against the raw series.

    Parameters
    ----------
    data : torch.Tensor

        for the forward transform. The inverse of each method is:

        - "minmax": `(data + 1) / 2 * range + min`
        - "standard": `data * std + mean`
        - "noncentered": `data * scale`

        `prepare_esn_data` with `return_stats=True`). The required keys
        depend on `method`: `{"min", "range"}` for "minmax",
        `{"mean", "std"}` for "standard", `{"scale"}` for "noncentered",
        and `{"mean", "maxdev"}` for "meanpreserving".

    -------
    torch.Tensor
        Data restored to the original scale, with the same shape as `data`.

    Raises
    ------
    ValueError
        If `method` is not a recognized normalization method.

    See Also
    --------
    normalize_data : The forward transform this function inverts.
    prepare_esn_data : Returns the fitted `stats` when `return_stats=True`.

    Examples
    --------

    >>> normalized, stats = normalize_data(data, method="standard")
    >>> restored = denormalize_data(normalized, method="standard", stats=stats)

    Sliding-window torch.utils.data.Dataset over time-series data.

    Slices one or more trajectories into fixed-length windows suitable for SGD (or streaming-algebraic) training of a reservoir model. Each item is an (input_window, target_window, washout) triple where input_window and target_window both have shape (window_len, D):

    • Forecasting (default, no external targets): the target is the input shifted forward by horizon steps, so window i covers source steps [start, start + window_len) for the input and [start + horizon, start + horizon + window_len) for the target.
    • Regression (external targets given): the target is the matching window sliced from targets at the same source positions as the input (horizon is ignored — supply pre-aligned targets).

    Windows are generated per trajectory and never straddle a trajectory boundary, so feeding the loader's batches with a per-batch reset_reservoirs() keeps reservoir state from leaking across unrelated trajectories. The first washout steps of every window are reported in the returned triple so the caller can exclude them from the loss while the reservoir synchronises.

    series

    Source data. A (T, D) tensor (one trajectory), a (B, T, D) tensor (B trajectories), or a list of (T, D) tensors of varying length (ragged trajectories).

    TYPE: torch.Tensor or sequence of torch.Tensor

    window_len

    Number of timesteps in each input/target window. Must be positive.

    TYPE: int

    horizon

    Forecast offset: the target window is the input window shifted forward by horizon steps. Ignored when targets is provided. Must be non-negative.

    self,
    series: torch.Tensor | Sequence[torch.Tensor],
    window_len: int,
    horizon: int = 1,
    stride: int = 1,
    washout: int = 0,
    targets: torch.Tensor | Sequence[torch.Tensor] | None = None,
    stats: dict[str, torch.Tensor] | None = None,
    norm_method: NormMethod | None = None,
    *,
    target_stats: dict[str, torch.Tensor] | None = None,
    target_norm_method: NormMethod | None = None,
) -> None:
    window_len = _validate_step_count("window_len", window_len)
    horizon = _validate_step_count("horizon", horizon, allow_zero=True)
    stride = _validate_step_count("stride", stride)
    washout = _validate_step_count("washout", washout, allow_zero=True)
    if washout >= window_len:
        raise ValueError(
            f"washout must satisfy 0 <= washout < window_len, got washout={washout}, "
            f"window_len={window_len}."
        )
    if (stats is None) != (norm_method is None):
        raise ValueError(
            "stats and norm_method must be provided together; got "
            f"stats={'set' if stats is not None else None}, norm_method={norm_method!r}."
        )

    if (target_stats is None) != (target_norm_method is None):
        raise ValueError("target_stats and target_norm_method must be provided together.")
    if target_stats is not None and targets is None:
        raise ValueError(
            "target_stats requires external targets; forecast targets use input stats."
        )

    self.window_len = window_len
    self.horizon = horizon
    self.stride = stride
    self.washout = washout
    self._stats = stats
    self._norm_method = norm_method
    self._target_stats = target_stats
    self._target_norm_method = target_norm_method

    self._inputs = _as_trajectory_list(series)
    self.feature_dim = self._inputs[0].shape[-1]

    self._has_external_targets = targets is not None
    if targets is not None:
        self._targets: list[torch.Tensor] = _as_trajectory_list(targets)
        if len(self._targets) != len(self._inputs):
            raise ValueError(
                f"series has {len(self._inputs)} trajectories but targets has "
                f"{len(self._targets)}; they must match."
            )
        for i, (x_traj, y_traj) in enumerate(zip(self._inputs, self._targets)):
            if x_traj.shape[0] != y_traj.shape[0]:
                raise ValueError(
                    f"trajectory {i}: series length ({x_traj.shape[0]}) and targets "
                    f"length ({y_traj.shape[0]}) must match."
                )
        self.target_dim = self._targets[0].shape[-1]
        # Targets are pre-aligned; no forecast offset is applied.
        self._offset = 0
    else:
        self._targets = self._inputs
        self.target_dim = self.feature_dim
        self._offset = horizon

    # One cumulative count per trajectory, rather than a Python tuple for
    # every overlapping window. Memory stays O(number of trajectories).
    self._window_ends: list[int] = []
    total = 0
    for traj in self._inputs:
        max_start = traj.shape[0] - self.window_len - self._offset
        total += max(0, max_start // self.stride + 1)
        self._window_ends.append(total)

    device : torch.device, str, or None, optional

    torch.Tensor
        Trajectory of shape `(1, n_timesteps, 1)`.

    # randomness, so no RNG is created (calling ``create_rng(None)`` would draw
    # from torch's global RNG as a side effect and perturb downstream torch
    # reproducibility for nothing).
    lag = max(1, round(tau / dt))

    n_timesteps: int,
    *,
    periods: float = 20.0,
    amplitude: float = 1.0,
    phase: float = 0.0,
    offset: float = 0.0,
    noise: float = 0.0,

    """Generate a (optionally noisy) sine wave.

    A simple, smooth, periodic signal — useful as a sanity-check task and for
    illustrating the API:

    ```python
    y_t = offset + amplitude * sin(2*pi * periods * t / n_timesteps + phase)
    ```

    Parameters
    ----------
    n_timesteps : int
        Number of timesteps to return (after the discarded transient).
    periods : float, optional
        Number of full oscillations over the returned window. Default `20.0`.
    amplitude : float, optional
        Peak amplitude. Default `1.0`.
    phase : float, optional
        Phase offset in radians. Default `0.0`.
    offset : float, optional
        Additive vertical offset. Default `0.0`.
    noise : float, optional
        Std of additive Gaussian noise (drawn from the seeded RNG). Default
        `0.0`.
    discard : int, optional
        Leading transient steps to drop. Default `0` (a pure sine has no
        transient).
    normalize : str or None, optional
        Normalization: `"standard"`, `"minmax"`, or `None`.
        Default `None` (raw values).
    seed : int, numpy.random.Generator, or None, optional
        Seed for the additive noise (via `resdag.utils.create_rng`).
        Default `0`.
    dtype : torch.dtype, optional
        Dtype of the returned tensor. Default `torch.float32` (matches
        torch's default, so the series drops straight into a model).
    device : torch.device, str, or None, optional
        Device of the returned tensor. Default `None` (CPU).

    Returns
    -------
    torch.Tensor
        Trajectory of shape `(1, n_timesteps, 1)`.
    """
    rng = create_rng(seed)
    total = n_timesteps + discard
    t = np.arange(total, dtype=np.float64)
    omega = 2.0 * np.pi * periods / max(1, n_timesteps)
    y = offset + amplitude * np.sin(omega * t + phase)
    if noise:
        y = y + noise * rng.standard_normal(total)

    series = _normalize(y[discard:].reshape(-1, 1), normalize)
    return _to_tensor(series, dtype, device)

    def kuramoto_sivashinsky(
    n_timesteps: int,
    *,
    n_grid: int = 64,
    length: float = 22.0,
    dt: float = 0.25,
    x0: np.ndarray | None = None,
    perturb: float = 1.0,
    discard: int = 1000,
    normalize: Normalize | None = None,
    seed: int | np.random.Generator | None = 0,
    dtype: torch.dtype = torch.float32,
    device: torch.device | str | None = None,
) -> torch.Tensor:
    r"""Generate a Kuramoto-Sivashinsky (KS) 1-D PDE trajectory.

    The KS equation is the canonical *spatiotemporally chaotic* benchmark for
    reservoir computing — a 1-D field $u(x, t)$ on a periodic domain of
    length `L` obeying

    $$
    u_t = -u\,u_x - u_{xx} - u_{xxxx},
    $$

    which develops a chaotic attractor whose number of positive Lyapunov
    exponents grows with `L`.  On the standard `L = 22` domain (Pathak et
    al. 2018) it is high-dimensionally chaotic — too large for a single global
    reservoir to forecast well, which is exactly what the parallel / local-state
    architecture (`resdag.models.parallel_esn`) targets.

    Integration uses the fourth-order exponential time-differencing Runge-Kutta
    scheme **ETDRK4** (Kassam & Trefethen 2005) in Fourier space — the standard,
    stiffly-accurate integrator for KS — so the linear $-u_{xx} - u_{xxxx}$
    term is handled exactly and only the nonlinear advection is stepped.

    The returned trajectory is the field sampled on the `n_grid` spatial
    points, so the output has `n_grid` feature channels: shape
    `(1, n_timesteps, n_grid)`.

    Parameters
    ----------
    n_timesteps : int
        Number of timesteps to return (after the discarded transient).
    n_grid : int, optional
        Number of spatial grid points (the feature dimension `D`).  Should be
        even for the real FFT grid.  Default `64`.
    length : float, optional
        Domain length `L` (periodic).  Default `22.0` — the canonical
        parallel-RC benchmark size.  The Lyapunov exponent in
        `resdag.metrics.CANONICAL_LAMBDA_MAX` is only valid for this value.
    dt : float, optional
        Integration / sampling step.  Default `0.25`.
    x0 : numpy.ndarray, optional
        Initial field of shape `(n_grid,)`.  `None` (default) uses the
        classic `cos(2*pi*x/L) * (1 + sin(2*pi*x/L))` seed.
    perturb : float, optional
        Std of a Gaussian perturbation added to the initial field (drawn from the
        seeded RNG), breaking symmetry so seeds give distinct trajectories on the
        same attractor.  Set to `0` for a fully deterministic start.  Default
        `1.0`.
    discard : int, optional
        Leading transient steps to drop so the trajectory sits on the attractor.
        Default `1000`.
    normalize : str or None, optional
        Per-channel normalization: `"standard"`, `"minmax"`, or `None`.
        Default `None` (KS
        is conventionally used on its native scale, and the channels are already
        comparable across the homogeneous spatial grid).
    seed : int, numpy.random.Generator, or None, optional
        Seed for the initial-field perturbation (via
        `resdag.utils.create_rng`).  Default `0`.
    dtype : torch.dtype, optional
        Dtype of the returned tensor.  Default `torch.float32`.
    device : torch.device, str, or None, optional
        Device of the returned tensor.  Default `None` (CPU).

    Returns
    -------
    torch.Tensor
        Trajectory of shape `(1, n_timesteps, n_grid)` — the KS field sampled
        on the spatial grid at each timestep.

    References
    ----------
    A.-K. Kassam and L. N. Trefethen, "Fourth-order time-stepping for stiff
    PDEs," SIAM J. Sci. Comput. 26(4), 1214-1233 (2005).

    J. Pathak, B. Hunt, M. Girvan, Z. Lu, and E. Ott, "Model-Free Prediction of
    Large Spatiotemporally Chaotic Systems from Data: A Reservoir Computing
    Approach," Phys. Rev. Lett. 120, 024102 (2018).

    See Also
    --------
    resdag.models.parallel_esn : Parallel local-state reservoir for KS / large
        spatiotemporal systems.
    """
    rng = create_rng(seed)

    # Spatial grid and initial field on the periodic domain [0, L).
    x = length * np.arange(n_grid, dtype=np.float64) / n_grid
    if x0 is None:
        u = np.cos(2.0 * np.pi * x / length) * (1.0 + np.sin(2.0 * np.pi * x / length))
    else:
        u = np.asarray(x0, dtype=np.float64).reshape(-1)
        if u.shape[0] != n_grid:
            raise ValueError(
                f"kuramoto_sivashinsky: x0 must have shape ({n_grid},) to match n_grid, "
                f"got shape {u.shape}."
            )
    if perturb:
        u = u + perturb * rng.standard_normal(n_grid)

    v = np.fft.rfft(u)

    # Fourier wavenumbers k for the rfft layout (0 .. n_grid/2).
    k = 2.0 * np.pi * np.fft.rfftfreq(n_grid, d=length / n_grid)
    # Linear operator L(k) = k^2 - k^4 (the -u_xx - u_xxxx term in Fourier space).
    lin = k**2 - k**4

    # ETDRK4 precomputed coefficients (Kassam & Trefethen 2005).  The phi-function
    # integrals are evaluated by averaging over a circle of ``m`` points in the
    # complex plane to avoid cancellation error when lin*dt is small.
    e = np.exp(dt * lin)
    e2 = np.exp(dt * lin / 2.0)
    m = 32
    roots = np.exp(1j * np.pi * (np.arange(1, m + 1) - 0.5) / m)
    lr = dt * lin[:, None] + roots[None, :]
    q = dt * ((np.exp(lr / 2.0) - 1.0) / lr).mean(axis=1).real
    f1 = dt * ((-4.0 - lr + np.exp(lr) * (4.0 - 3.0 * lr + lr**2)) / lr**3).mean(axis=1).real
    f2 = dt * ((2.0 + lr + np.exp(lr) * (-2.0 + lr)) / lr**3).mean(axis=1).real
    f3 = dt * ((-4.0 - 3.0 * lr - lr**2 + np.exp(lr) * (4.0 - lr)) / lr**3).mean(axis=1).real

    # Nonlinear term N(v) = -0.5 * i * k * FFT(IFFT(v)^2).
    g = -0.5j * k

    def nonlinear(vh: np.ndarray) -> np.ndarray:
        real = np.fft.irfft(vh, n=n_grid)
        return g * np.fft.rfft(real**2)

    total = n_timesteps + discard
    out = np.empty((total, n_grid), dtype=np.float64)
    for i in range(total):
        out[i] = np.fft.irfft(v, n=n_grid)
        # One ETDRK4 step.
        nv = nonlinear(v)
        a = e2 * v + q * nv
        na = nonlinear(a)
        b = e2 * v + q * na
        nb = nonlinear(b)
        c = e2 * a + q * (2.0 * nb - nv)
        nc = nonlinear(c)
        v = e * v + nv * f1 + 2.0 * (na + nb) * f2 + nc * f3

    series = _normalize(out[discard:], normalize)
    return _to_tensor(series, dtype, device)
