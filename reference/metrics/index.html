    Metrics¶

    Forecast-quality and dynamical metrics for reservoir models, with first-class support for reporting horizons in Lyapunov times — the natural clock of a chaotic attractor — rather than raw integration steps. A valid-prediction time in Lyapunov times (\(\text{VPT}_{\Lambda t} = \text{steps} \cdot dt \cdot \lambda_\mathrm{max}\)) expresses a physical horizon relative to the system's instability rate. Comparisons still require matching error definitions, thresholds, normalization, forecast origins and censoring conventions. Supply the actual sampling interval and a suitable exponent when changing system parameters; canonical table values are reference values for their stated systems.

    The conversions, the canonical \(\lambda_\mathrm{max}\) tables, valid_prediction_time, and reservoir_lyapunov are pure PyTorch/NumPy and always available. The series- and System-based paths of largest_lyapunov need the optional resdag[dynamics] extra (tsdynamics, Python ≥ 3.12) — see Work · Lyapunov time for the prose walkthrough.

    Forecast accuracy¶

    valid_prediction_time counts the contiguous prefix strictly below its threshold. Its NRMSE scales come from the supplied truth tensor, and per-step batch errors are reduced with the median. The common tuning workflow instead uses fixed training scales; record that distinction when comparing results. rmse, nrmse and r2 return aggregate scalar errors rather than a valid prefix.

    def valid_prediction_time(
    pred: torch.Tensor,
    truth: torch.Tensor,
    *,
    threshold: float = 0.3,
    metric: str = "nrmse",
    units: str = "steps",
    dt: float | None = None,
    lambda_max: float | None = None,
    dataset: str | None = None,
    **kw: float,
) -> float:
    """Valid Prediction Time: contiguous steps a forecast stays accurate.

    Per-step error is the **NRMSE** — the RMSE across feature channels, each
    channel normalised by the per-dimension standard deviation of `truth` over
    the `(batch, time)` axes — reduced across the batch with the **median**.
    The VPT is the number of steps, counting from the start, whose error stays
    strictly below `threshold` (`0` if the very first step is already over).

    This matches `resdag.hpo.losses.forecast_horizon` exactly (that copy
    is kept out of the optional-HPO import path); see the module docstring.

    Parameters
    ----------
    pred, truth : torch.Tensor
        Forecast and ground truth of shape `(batch, time, dim)`.
    threshold : float, default=0.3
        NRMSE threshold below which a step counts as "valid".
    metric : {"nrmse"}, default="nrmse"
        Per-step error metric.  Only NRMSE is implemented (the reservoir-computing
        standard); the argument exists for forward compatibility.
    units : {"steps", "lyapunov"}, default="steps"
        Return the horizon in raw steps, or converted to Lyapunov times
        (`steps * dt * lambda_max`).  `"lyapunov"` needs `dt` and
        `lambda_max`, or a known `dataset` name to infer them.
    dt : float, optional
        Integration step, required for `units="lyapunov"` unless inferable
        from `dataset`.
    lambda_max : float, optional
        Largest Lyapunov exponent, required for `units="lyapunov"` unless
        inferable from a chaotic `dataset`.
    dataset : str, optional
        A built-in generator name (`"lorenz"`, `"rossler"`,
        `"mackey_glass"`, ...) used to look up `dt` / `lambda_max` when
        they are not given explicitly.
    **kw
        Extra keys forwarded to inference; `tau=` selects the Mackey-Glass
        exponent.

    Returns
    -------
    float
        The VPT: an integer step count as a `float` when `units="steps"`, or
        the horizon in Lyapunov times when `units="lyapunov"`.

    Raises
    ------
    ValueError
        If `metric` is not `"nrmse"`, `units` is unknown, or
        `units="lyapunov"` cannot resolve `dt` / `lambda_max`.

    Examples
    --------
    >>> import torch
    >>> pred = torch.zeros(1, 100, 3)
    >>> truth = torch.zeros(1, 100, 3)
    >>> valid_prediction_time(pred, truth)  # identical -> full horizon
    100.0
    """
    if metric != "nrmse":
        raise ValueError(f"Unknown metric {metric!r}; only 'nrmse' is implemented.")
    if units not in ("steps", "lyapunov"):
        raise ValueError(f"Unknown units {units!r}; expected 'steps' or 'lyapunov'.")

    p = pred.detach().cpu().double().numpy()
    t = truth.detach().cpu().double().numpy()
    # Compare over the overlapping prefix if the two differ in length.
    n = min(p.shape[1], t.shape[1])
    p, t = p[:, :n], t[:, :n]

    scale = t.std(axis=(0, 1), keepdims=True)
    scale = np.where(scale == 0.0, 1.0, scale)
    err = np.sqrt((((p - t) / scale) ** 2).mean(axis=2))  # (batch, time)
    e_t = np.median(err, axis=0)  # (time,)

    below = e_t < threshold
    if below.size == 0 or not below[0]:
        steps = 0
    elif (~below).any():
        steps = int(np.argmax(~below))
    else:
        steps = int(below.size)

    if units == "steps":
        return float(steps)

    dt_r, lam_r = _infer_dt_lambda(dataset, dt, lambda_max, **kw)
    return steps_to_lyapunov(steps, dt_r, lam_r)

    nrmse(pred: Tensor, truth: Tensor, *, normalization: str = 'std') -> float

    Normalised RMSE — scale-free forecast error.

    The RMSE is normalised so the metric is invariant to the absolute scale of the data, which is what makes a fixed error threshold (the basis of valid_prediction_time) meaningful across systems. Two conventions:

    def nrmse(
    pred: torch.Tensor,
    truth: torch.Tensor,
    *,
    normalization: str = "std",
) -> float:
    """Normalised RMSE — scale-free forecast error.

    The RMSE is normalised so the metric is invariant to the absolute scale of
    the data, which is what makes a fixed error *threshold* (the basis of
    `valid_prediction_time`) meaningful across systems.  Two conventions:

    - `normalization="std"` (default) — per-feature RMSE, each channel
      divided by the **per-dimension standard deviation** of `truth` over the
      `(batch, time)` axes, then combined across channels.  This is *exactly*
      the per-step NRMSE that `valid_prediction_time` thresholds (reduced
      here over the whole trajectory rather than per step), so the two never
      disagree.
    - `normalization="range"` — the scalar RMSE over all elements divided by
      the peak-to-peak range (`max - min`) of `truth`.

    Parameters
    ----------
    pred, truth : torch.Tensor
        Forecast and ground truth of shape `(batch, time, dim)`, compared over
        their overlapping time prefix.
    normalization : {"std", "range"}, default="std"
        Whether to normalise by the per-dimension standard deviation of the
        truth (the reservoir-computing standard, matching
        `valid_prediction_time`) or by its global peak-to-peak range.

    Returns
    -------
    float
        The normalised RMSE (`0` for a perfect forecast).  A value of `1`
        under `"std"` normalisation corresponds to the error of predicting the
        per-channel mean.

    Raises
    ------
    ValueError
        If `normalization` is not `"std"` or `"range"`.

    Examples
    --------
    >>> import torch
    >>> truth = torch.randn(1, 200, 3)
    >>> nrmse(truth, truth)  # identical
    0.0
    """
    if normalization not in ("std", "range"):
        raise ValueError(f"Unknown normalization {normalization!r}; expected 'std' or 'range'.")
    p, t = _as_2d_pair(pred, truth)
    if normalization == "std":
        scale = t.std(axis=(0, 1), keepdims=True)
        scale = np.where(scale == 0.0, 1.0, scale)
        # Per-step RMSE across channels of the standardised residual, then a
        # single RMS reduction across (batch, time) — the trajectory-level
        # counterpart of valid_prediction_time's per-step error.
        err = np.sqrt((((p - t) / scale) ** 2).mean(axis=2))  # (batch, time)
        return float(np.sqrt((err**2).mean()))
    # normalization == "range"
    span = float(t.max() - t.min())
    if span == 0.0:
        span = 1.0
    return float(np.sqrt(np.mean((p - t) ** 2)) / span)

    TYPE: Tensor

    def r2(pred: torch.Tensor, truth: torch.Tensor) -> float:
    """Coefficient of determination $R^2$ of a forecast.

    The standard variance-explained score, pooled over all elements:

    $$
    R^2 = 1 - \\frac{\\sum (\\hat y - y)^2}{\\sum (y - \\bar y)^2},
    $$

    where $\\bar y$ is the grand mean of `truth`.  `1.0` is a perfect
    forecast; `0.0` matches the skill of predicting the mean; negative values
    are worse than the mean.

    Parameters
    ----------
    pred, truth : torch.Tensor
        Forecast and ground truth of shape `(batch, time, dim)`, compared over
        their overlapping time prefix.

    Returns
    -------
    float
        The $R^2$ score.  Returns `1.0` when `truth` is constant and
        the forecast matches it exactly (zero residual and zero total variance),
        else `0.0` for a constant truth with any residual.

    Examples
    --------
    >>> import torch
    >>> truth = torch.randn(1, 200, 3)
    >>> r2(truth, truth)
    1.0
    """
    p, t = _as_2d_pair(pred, truth)
    ss_res = float(np.sum((p - t) ** 2))
    ss_tot = float(np.sum((t - t.mean()) ** 2))
    if ss_tot == 0.0:
        # Constant truth: R^2 is conventionally 1 for a perfect fit, else 0.
        return 1.0 if ss_res == 0.0 else 0.0
    return 1.0 - ss_res / ss_tot

    $$
    J_t = (1-\\alpha) I + \\alpha\\, \\mathrm{diag}\\!\\big(f'(\\mathrm{pre}_t)\\big)\\, W_\\mathrm{hh},

        dynamics, not the batch).

        tighter estimate.

    ValueError

    horizon = _validate_step_count("horizon", horizon)
    transient = _validate_step_count("transient", transient, allow_zero=True)
    k = _validate_step_count("k", k)
    cell = _diagnostic_cell(source, tanh_esn=True)
    streams = [warmup_inputs] if isinstance(warmup_inputs, torch.Tensor) else list(warmup_inputs)
    if not streams or any(x.ndim != 3 or x.shape[0] < 1 or x.shape[1] < 1 for x in streams):
        raise ValueError("warmup_inputs must contain non-empty (batch, time, features) streams.")
    if any(x.shape[:2] != streams[0].shape[:2] for x in streams):
        raise ValueError("warmup input streams must have matching batch and time dimensions.")
    inputs = [x[:1].detach().cpu().to(dtype=torch.float64) for x in streams]
    if not all(bool(torch.isfinite(x).all()) for x in inputs):
        raise ValueError("warmup inputs must be finite.")
    _, state = _drive_cell(cell, inputs)
    n = int(cell.state_size)
    if k > n:
        raise ValueError(f"k must be in [1, reservoir_size={n}], got {k}.")
    weight = _esn_recurrent_jacobian_weight(cell)
    alpha = torch.as_tensor(cell.leak_rate, dtype=torch.float64)
    if alpha.ndim == 0:
        alpha = alpha.expand(n)
    projected = cell.project_inputs(inputs)
    generator = torch.Generator().manual_seed(int(seed)) if seed is not None else None
    frame = torch.linalg.qr(torch.randn(n, k, dtype=torch.float64, generator=generator))[0]
    log_sums = torch.zeros(k, dtype=torch.float64)
    identity = torch.eye(n, dtype=torch.float64)
    with torch.no_grad():
        for step in range(transient + horizon):
            t = step % inputs[0].shape[1]
            # Match the live cell's calibrated preactivation, then advance via
            # its actual implementation rather than a second update equation.
            pre = projected[:, t] + cell._recurrent(state)
            if cell._has_intrinsic:
                pre = cell._intrinsic_gain * pre + cell._intrinsic_bias
            gate = 1.0 - torch.tanh(pre).reshape(n).square()
            jacobian = alpha[:, None] * gate[:, None] * weight
            jacobian = jacobian + (1.0 - alpha)[:, None] * identity
            _, state = cell.step(projected[:, t], state)
            frame, triangular = torch.linalg.qr(jacobian @ frame)
            if step >= transient:
                growth = triangular.diagonal().abs().clamp_min(1e-300)
                log_sums += growth.log()
    exponents = (log_sums / horizon).numpy()
    return float(exponents[0]) if k == 1 else exponents

    memory_capacity(
    source: Any,
    *,
    max_delay: int = 100,
    n_samples: int = 2000,

    alpha: float = 1e-08,
    input_low: float = -1.0,

) -> float | tuple[float, ndarray]

    Linear short-term memory capacity of a reservoir (Jaeger 2001).

    Drives the reservoir with a scalar i.i.d. uniform input \(u_t\) and, for each delay \(k = 1 \dots\) max_delay, fits a linear readout from the reservoir state \(h_t\) to the delayed input \(u_{t-k}\). The memory capacity is the sum of the squared correlations of the reconstruction

    \[ MC = \sum_{k=1}^{k_{\max}} R^2_k, \qquad R^2_k = \frac{\operatorname{cov}(\hat u_{t-k},\, u_{t-k})^2} {\operatorname{var}(\hat u_{t-k})\,\operatorname{var}(u_{t-k})}, \]

    the standard forgetting-curve integral (Jaeger, Short-term memory in echo state networks, 2001). Readouts are fitted on one random input trajectory and scored on an independently generated, independently warmed trajectory. No evaluation samples enter fitting or centering statistics.

    The theoretical population capacity is at most the number of reservoir states, under the usual independent-input assumptions. This finite-sample estimator may exceed that bound through sampling noise, particularly for many delays and few test samples. It is not guaranteed to increase with spectral radius. Increase test_samples and repeat seeds to assess uncertainty; this diagnostic is not an autonomous forecast score.

    The actual cell update runs on a local CPU float64 evaluation copy. Caller weights, cached state, device and training mode are preserved. Training-only noise is disabled. One augmented least-squares solve fits all delayed targets together, avoiding the loss of conditioning from normal equations.

    PARAMETER DESCRIPTION
    source

    The reservoir to probe, or a model containing exactly one ESN reservoir. The reservoir must accept a scalar feedback (feedback_size == 1), since memory capacity is defined for a one-dimensional i.i.d. drive.

    TYPE: BaseReservoirLayer or ESNModel

    max_delay

    Largest delay \(k_{\max}\) in the forgetting sum. Should comfortably exceed the reservoir's memory (a few times N for a linear reservoir) so the tail \(R^2_k \approx 0\) and the sum has converged.

    TYPE: int DEFAULT: 100

    n_samples

    Number of (state, delayed-input) samples used to fit each linear readout after washout and delay history. More samples than reservoir states are recommended; positive ridge regularization permits fewer.

    TYPE: int DEFAULT: 2000

    washout

    Leading driven steps discarded so the reservoir state reflects the input history rather than the (zero) initial condition.

    TYPE: int DEFAULT: 200

    alpha

    Non-negative ridge regularization on centered reservoir features. The intercept is unpenalized. Zero selects an unregularized least-squares fit; positive values stabilize correlated or underdetermined states.

    TYPE: float DEFAULT: 1e-8

    input_low

    Lower bound of the uniform input distribution.

    TYPE: float DEFAULT: -1.0

    input_high

    Upper bound of the uniform input distribution \(u_t \sim \mathcal{U}(\text{low}, \text{high})\). The default symmetric [-1, 1] is the Jaeger convention; a smaller range keeps a tanh reservoir nearer its linear regime (larger MC).

    def memory_capacity(
    source: Any,
    *,
    max_delay: int = 100,
    n_samples: int = 2000,
    washout: int = 200,
    alpha: float = 1e-8,
    input_low: float = -1.0,
    input_high: float = 1.0,
    seed: int = 0,
    return_curve: bool = False,
    test_samples: int | None = None,
) -> float | tuple[float, np.ndarray]:
    r"""Linear short-term memory capacity of a reservoir (Jaeger 2001).

    Drives the reservoir with a scalar i.i.d. uniform input $u_t$ and, for
    each delay $k = 1 \dots$ `max_delay`, fits a **linear** readout from
    the reservoir state $h_t$ to the delayed input $u_{t-k}$.  The
    memory capacity is the sum of the squared correlations of the reconstruction

    $$
    MC = \sum_{k=1}^{k_{\max}} R^2_k, \qquad
    R^2_k = \frac{\operatorname{cov}(\hat u_{t-k},\, u_{t-k})^2}
                 {\operatorname{var}(\hat u_{t-k})\,\operatorname{var}(u_{t-k})},
    $$

    the standard forgetting-curve integral (Jaeger, *Short-term memory in echo
    state networks*, 2001). Readouts are fitted on one random input trajectory
    and scored on an independently generated, independently warmed trajectory.
    No evaluation samples enter fitting or centering statistics.

    The theoretical population capacity is at most the number of reservoir
    states, under the usual independent-input assumptions. This finite-sample
    estimator may exceed that bound through sampling noise, particularly for
    many delays and few test samples. It is not guaranteed to increase with
    spectral radius. Increase `test_samples` and repeat seeds to assess
    uncertainty; this diagnostic is not an autonomous forecast score.

    The actual cell update runs on a local CPU float64 evaluation copy. Caller
    weights, cached state, device and training mode are preserved. Training-only
    noise is disabled. One augmented least-squares solve fits all delayed
    targets together, avoiding the loss of conditioning from normal equations.

    Parameters
    ----------
    source : BaseReservoirLayer or ESNModel
        The reservoir to probe, or a model containing exactly one ESN reservoir.
        The reservoir must accept a **scalar** feedback (`feedback_size == 1`),
        since memory capacity is defined for a one-dimensional i.i.d. drive.
    max_delay : int, default=100
        Largest delay $k_{\max}$ in the forgetting sum.  Should comfortably
        exceed the reservoir's memory (a few times `N` for a linear reservoir)
        so the tail $R^2_k \approx 0$ and the sum has converged.
    n_samples : int, default=2000
        Number of `(state, delayed-input)` samples used to fit each linear
        readout after washout and delay history. More samples than reservoir
        states are recommended; positive ridge regularization permits fewer.
    washout : int, default=200
        Leading driven steps discarded so the reservoir state reflects the input
        history rather than the (zero) initial condition.
    alpha : float, default=1e-8
        Non-negative ridge regularization on centered reservoir features. The
        intercept is unpenalized. Zero selects an unregularized least-squares
        fit; positive values stabilize correlated or underdetermined states.
    input_low : float, optional
        Lower bound of the uniform input distribution.
    input_high : float, optional
        Upper bound of the uniform input distribution $u_t \sim \mathcal{U}(\text{low}, \text{high})$.  The default symmetric `[-1, 1]`
        is the Jaeger convention; a smaller range keeps a `tanh` reservoir
        nearer its linear regime (larger MC).
    seed : int, default=0
        Seed for the input draw, so the estimate is fully deterministic.
    test_samples : int or None, default=None
        Number of independent scoring samples, at least 2. `None` uses
        `max(1000, n_samples)` to limit chance correlations at long delays.
    return_curve : bool, default=False
        If `True`, also return the per-delay forgetting curve
        $(R^2_1, \dots, R^2_{k_{\max}})$ as a `(max_delay,)` array.

    Returns
    -------
    float or tuple of (float, numpy.ndarray)
        The memory capacity $MC$.  When `return_curve` is `True`, a
        `(MC, curve)` pair where `curve[k-1]` is $R^2_k$.

    Raises
    ------
    ValueError
        If the reservoir needs multiple feedback channels or an external driver,
        counts are invalid, training/scoring samples are fewer than 2, or the
        distribution bounds / regularization are invalid.

    Examples
    --------
    >>> from resdag.layers import ESNLayer
    >>> res = ESNLayer(100, feedback_size=1, spectral_radius=0.9, seed=0)
    >>> mc = memory_capacity(res, max_delay=120, n_samples=2000)
    >>> mc >= 0.0
    True

    See Also
    --------
    effective_spectral_radius : Realized contraction rate of the driven reservoir.
    """
    from resdag.data.prepare import _validate_step_count
    from resdag.metrics.lyapunov import _diagnostic_cell, _drive_cell

    max_delay = _validate_step_count("max_delay", max_delay)
    n_samples = _validate_step_count("n_samples", n_samples)
    washout = _validate_step_count("washout", washout, allow_zero=True)
    test_samples = _validate_step_count(
        "test_samples", max(1000, n_samples) if test_samples is None else test_samples
    )
    if n_samples < 2 or test_samples < 2:
        raise ValueError("n_samples and test_samples must both be at least 2.")
    if not np.isfinite(alpha) or alpha < 0:
        raise ValueError("alpha must be finite and non-negative.")
    if not (np.isfinite(input_low) and np.isfinite(input_high) and input_low < input_high):
        raise ValueError("input_low and input_high must be finite with input_low < input_high.")
    cell = _diagnostic_cell(source)
    if getattr(cell, "feedback_size", None) != 1 or getattr(cell, "input_size", None) not in (
        None,
        0,
    ):
        raise ValueError("memory_capacity requires feedback_size == 1 and no external driver.")
    generator = torch.Generator().manual_seed(int(seed))
    start = washout + max_delay

    def samples(count: int) -> tuple[torch.Tensor, torch.Tensor]:
        u = torch.rand(1, start + count, 1, generator=generator, dtype=torch.float64)
        u = input_low + (input_high - input_low) * u
        states, _ = _drive_cell(cell, [u])
        times = torch.arange(start, start + count)
        delays = torch.arange(1, max_delay + 1)
        targets = u[0, times[:, None] - delays, 0]
        return states[0, start:], targets

    # Independent i.i.d. streams, independently warmed from the reset template:
    # no evaluation target or state belongs to the fitting sequence.
    train_x, train_y = samples(n_samples)
    test_x, test_y = samples(test_samples)
    x_mean, y_mean = train_x.mean(0), train_y.mean(0)
    centered = train_x - x_mean
    centered_targets = train_y - y_mean
    if alpha > 0:
        # Solve the equivalent ridge least-squares problem directly. Forming
        # X.T @ X squares the condition number and can round away a positive
        # alpha for large, correlated states, leaving a singular Gram matrix.
        n_features = centered.shape[1]
        centered = torch.cat(
            (centered, np.sqrt(alpha) * torch.eye(n_features, dtype=centered.dtype))
        )
        centered_targets = torch.cat(
            (centered_targets, centered_targets.new_zeros(n_features, max_delay))
        )
    coefficients = torch.linalg.lstsq(centered, centered_targets).solution
    predictions = (test_x - x_mean) @ coefficients + y_mean
    predictions = predictions - predictions.mean(0)
    targets = test_y - test_y.mean(0)
    denominator = predictions.square().sum(0) * targets.square().sum(0)
    correlations = (predictions * targets).sum(0).square()
    curve_tensor = torch.where(denominator > 0, correlations / denominator, 0.0).clamp(0, 1)
    curve = curve_tensor.numpy()
    capacity = float(curve.sum())
    return (capacity, curve) if return_curve else capacity

    mean it need not be below the weight spectral radius, and it does not bound

    trajectories from CUDA and MPS reservoirs are both supported.

    source : BaseReservoirLayer or ESNModel
        The reservoir whose recurrent Jacobian is analysed, or a model
        containing exactly one standard `ESNCell` reservoir with `tanh`.
        Alternative cell update equations are explicitly unsupported.
    states : torch.Tensor
        Reservoir states sampled along an attractor trajectory, of shape
        `(batch, time, N)` or `(time, N)` (with `N` the reservoir size).
        Supply consecutive states from each trajectory, as returned by the
        reservoir on representative input. For leak rate 1 the activation is
        the state itself. For a leaky reservoir it is recovered from adjacent
        states as `(h_t - (1-alpha)*h_{t-1}) / alpha`; the first state of each
        trajectory is excluded because its predecessor is unavailable.

        Cap on the number of trajectory states the mean is taken over; the
        states are subsampled on an evenly spaced deterministic grid so
        the estimate stays manageable for a long trajectory —
        each state costs one $N \times N$ eigenvalue solve.

        Retained for API compatibility; even subsampling uses no randomness.

    Returns
    -------
    float
        The mean realized spectral radius $\langle \rho(J_t) \rangle$ over
        the sampled states, in per-step units. Leakage and non-normal recurrent
        weights mean this need not be below the weight spectral radius.

    Raises
    ------
    ValueError
        If `source` has no (or more than one) ESN reservoir, or if `states`
        does not have a trailing dimension equal to the reservoir size.
    NotImplementedError
        If the cell is not a standard tanh `ESNCell`.

    Examples
    --------
    >>> import torch
    >>> from resdag.layers import ESNLayer
    >>> res = ESNLayer(100, feedback_size=1, spectral_radius=0.9, seed=0)
    >>> u = torch.rand(1, 1500, 1) * 2 - 1

    >>> esr < 0.9  # tanh saturation contracts below the nominal weight radius

    from resdag.metrics.lyapunov import _diagnostic_cell, _esn_recurrent_jacobian_weight

    cell = _diagnostic_cell(source, tanh_esn=True)
    weight = _esn_recurrent_jacobian_weight(cell)
    n = weight.shape[0]
    h = states.detach().cpu().to(dtype=torch.float64)
    if h.ndim not in (2, 3) or h.shape[-1] != n:
        raise ValueError(f"states must have shape (time,{n}) or (batch,time,{n}).")
    if not bool(torch.isfinite(h).all()):
        raise ValueError("states must be finite.")
    alpha = torch.as_tensor(cell.leak_rate, dtype=torch.float64)
    if alpha.ndim == 0:
        alpha = alpha.expand(n)
    if not bool((alpha == 1).all()):
        if h.shape[-2] < 2:
            raise ValueError(
                "Leaky reservoirs need at least two consecutive states per trajectory."
            )

        h = (h[..., 1:, :] - (1 - alpha) * h[..., :-1, :]) / alpha

    if not h.shape[0]:
        raise ValueError("states must contain at least one trajectory state.")
    if h.shape[0] > max_states:

        jacobian += (1 - alpha)[:, None] * identity
        radii.append(torch.linalg.eigvals(jacobian).abs().max())
    return float(torch.stack(radii).mean())

    \[ C(r) = \frac{2}{M(M-1)} \sum_{i<j} \Theta\!\big(r - \lVert x_i - x_j \rVert\big) \]

    counts the fraction of point pairs closer than \(r\). On a \(D_2\)-dimensional attractor it scales as \(C(r) \sim r^{D_2}\) over an intermediate ("scaling") range of \(r\), so \(D_2\) is the slope of \(\log C(r)\) against \(\log r\) fit over that range.

    This is the standard attractor-fidelity metric for reservoir forecasts: a free-running forecast that reproduces the true system's climate (its long-run geometry) matches the truth's correlation dimension, even when the pointwise trajectory has long since decorrelated.

    Reference values (used to validate this implementation):

    • Lorenz-63 \(D_2 \approx 2.05\) (literature; Grassberger & Procaccia 1983).
    • A limit cycle / closed curve \(D_2 \approx 1.0\) (a 1-D manifold).
    • \(d\)-dimensional i.i.d. noise \(D_2 \approx d\) (it fills the embedding space).

    TYPE: float DEFAULT: 0.5

    TYPE: tuple of float DEFAULT: (0.1, 0.5)

    a trajectory lives on, via the Grassberger-Procaccia algorithm (Grassberger
    & Procaccia, *Characterization of strange attractors*, 1983).  The
    correlation sum

    $$
    C(r) = \frac{2}{M(M-1)} \sum_{i<j} \Theta\!\big(r - \lVert x_i - x_j \rVert\big)
    $$

    counts the fraction of point pairs closer than $r$.  On a
    $D_2$-dimensional attractor it scales as $C(r) \sim r^{D_2}$ over
    an intermediate ("scaling") range of $r$, so $D_2$ is the slope
    of $\log C(r)$ against $\log r$ fit over that range.

    This is the standard **attractor-fidelity** metric for reservoir forecasts:
    a free-running forecast that reproduces the true system's *climate* (its
    long-run geometry) matches the truth's correlation dimension, even when the
    pointwise trajectory has long since decorrelated.

    Reference values (used to validate this implementation):

    * **Lorenz-63** $D_2 \approx 2.05$ (literature; Grassberger & Procaccia
      1983).
    * **A limit cycle / closed curve** $D_2 \approx 1.0$ (a 1-D manifold).
    * **$d$-dimensional i.i.d. noise** $D_2 \approx d$ (it fills the
      embedding space).

    Parameters
    ----------
    trajectory : torch.Tensor or numpy.ndarray
        The attractor trajectory, of shape `(time, dim)` (a 1-D `(time,)`
        signal is treated as a single channel).  A leading singleton batch axis
        `(1, time, dim)` is squeezed.  For a fair comparison of a forecast to
        the truth, embed both the same way and pass equal-length windows.
    n_bins : int, default=20
        Number of log-spaced radii $r$ at which $C(r)$ is evaluated.
    r_min_frac : float, optional
        Smallest radius as a fraction of the largest pairwise distance.
    r_max_frac : float, optional
        Largest radius as a fraction of the largest pairwise distance.
        The radius grid spans `[r_min_frac, r_max_frac] * d_max` where
        `d_max` is the largest pairwise distance, so the grid adapts to the
        attractor's size.
    fit_window : tuple of float, default=(0.1, 0.5)
        The scaling region over which the $\log C$ vs $\log r$ slope
        is fit, given as fractions of the (valid) `log r` span.  The default
        lower-middle window avoids the noisy small-$r$ depletion and the
        large-$r$ saturation that bias a full-range fit.
    max_points : int, default=2000
        Cap on the number of trajectory points used (the pair count is
        $O(M^2)$); a longer trajectory is uniformly subsampled.  `2000`
        points (~2M pairs) already give a stable dimension for Lorenz-63.
    seed : int, default=0
        Seed for the subsampling draw, so the estimate is deterministic.

    Returns
    -------
    float
        The estimated correlation dimension $D_2$.

    Raises
    ------
    ValueError
        If `trajectory` is not 1-D/2-D (after squeezing a batch axis), has
        fewer than 2 points, or is a single constant point (zero extent).

    Notes
    -----
    The estimate is a **geometry** metric, not an error: two trajectories on the
    *same* attractor but out of phase share a correlation dimension.  Compare a
    forecast's dimension to the truth's (`|D2_pred - D2_truth|`) to score
    climate reconstruction — this is what
    `resdag.hpo.losses.attractor_dimension_error` optimises.

    Examples
    --------
    >>> import numpy as np
    >>> t = np.linspace(0, 2 * np.pi, 3000, endpoint=False)
    >>> circle = np.stack([np.cos(t), np.sin(t)], axis=1)
    >>> abs(correlation_dimension(circle) - 1.0) < 0.15
    True
    """
    if isinstance(trajectory, torch.Tensor):
        x = trajectory.detach().cpu().double().numpy()
    else:
        x = np.asarray(trajectory, dtype=np.float64)

    if x.ndim == 3 and x.shape[0] == 1:
        x = x[0]
    if x.ndim == 1:
        x = x[:, None]
    if x.ndim != 2:
        raise ValueError(
            f"trajectory must be 1-D (time,), 2-D (time, dim), or 3-D (1, time, dim); "
            f"got shape {np.asarray(trajectory).shape}."
        )
    n_points = x.shape[0]
    if n_points < 2:
        raise ValueError(f"trajectory needs at least 2 points, got {n_points}.")

    if n_points > max_points:
        rng = np.random.default_rng(seed)
        idx = rng.choice(n_points, size=max_points, replace=False)
        idx.sort()
        x = x[idx]
        n_points = max_points

    # Upper-triangular pairwise Euclidean distances.
    diff = x[:, None, :] - x[None, :, :]
    dmat = np.sqrt(np.einsum("ijk,ijk->ij", diff, diff))
    iu = np.triu_indices(n_points, k=1)
    dists = dmat[iu]
    dists = dists[dists > 0.0]
    if dists.size == 0:
        raise ValueError(
            "trajectory has zero extent (all points coincide); the correlation "
            "dimension is undefined."
        )
    d_max = float(dists.max())

    radii = np.logspace(
        np.log10(r_min_frac * d_max),
        np.log10(r_max_frac * d_max),
        n_bins,
    )
    # Correlation sum C(r): fraction of pairs closer than r. searchsorted on the
    # sorted distances turns each count into an O(log) lookup.
    dists_sorted = np.sort(dists)
    counts = np.searchsorted(dists_sorted, radii, side="left")
    corr_sum = counts / dists_sorted.size

    valid = corr_sum > 0.0
    log_r = np.log(radii[valid])
    log_c = np.log(corr_sum[valid])
    if log_r.size < 2:
        raise ValueError(
            "not enough non-empty correlation-sum bins to fit a slope; "
            "increase n_bins or the trajectory length."
        )

    lo, hi = fit_window
    r0, r1 = log_r.min(), log_r.max()
    span = r1 - r0
    if span <= 0.0:
        fit_mask = np.ones_like(log_r, dtype=bool)
    else:
        fit_mask = (log_r >= r0 + lo * span) & (log_r <= r0 + hi * span)
        if fit_mask.sum() < 2:
            fit_mask = np.ones_like(log_r, dtype=bool)

    slope = float(np.polyfit(log_r[fit_mask], log_c[fit_mask], 1)[0])
    return slope
